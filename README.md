Restify 🏨
Relax • Recharge • Repeat
Restify is a full-stack hourly rest pod booking and property management platform designed to help people discover and book a comfortable place to rest for a few hours in busy urban areas.
Long commutes, travel, airport delays, and packed schedules can leave people needing a short break without requiring an overnight hotel stay. Restify aims to make short-term rest easier to discover and manage through one online platform.

✨ Features
For customers
- Browse and search available rest pods.
- Filter listings by location, city, price, and capacity.
- View pod details, amenities, and pricing.
- Check availability and create bookings.
- View booking history and manage cancellations.
- Manage account and profile information.
For property owners
- Create and manage pod listings.
- Update property details, prices, capacity, and amenities.
- View customer bookings.
- Track earnings.
For administrators
- Review partner applications.
- Approve or reject property partners.
- Manage pod listings and platform workflows.

🔐 Authentication and Roles
Restify uses JWT-based authentication and role-based access control to support different workflows for:
- Customer — discovers pods and manages bookings.
- Owner — manages pod listings, bookings, and earnings.
- Admin — reviews partner applications and manages platform operations.
🔄 Typical User Flow
1. Browse or search for a rest pod.
2. Open the listing to review its details.
3. Check availability and booking information.
4. Create and manage a booking.
Property owners can apply to become partners. Administrators review applications, and approved partners can access owner functionality.
🏗️ How It Works
The React frontend communicates with a Node.js and Express backend through REST APIs. The backend handles application logic, authentication, authorization, booking workflows, and database operations using MongoDB and Mongoose.
